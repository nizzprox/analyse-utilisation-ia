# Analyse de l’utilisation de l’intelligence artificielle

Projet de statistique descriptive portant sur les habitudes
d’utilisation de l’intelligence artificielle générative chez
les étudiants en Sciences de la nature.

## Objectif

Décrire la fréquence et la durée d’utilisation de l’IA,
les principaux usages et outils, la vérification des réponses
ainsi que l’utilité perçue.

## Données

Les données utilisées dans ce projet sont fictives et ont été
construites à des fins pédagogiques. La base de données comprendra
75 unités statistiques fictives.

## Technologies

- Python
- NumPy
- pandas
- Matplotlib

## Structure

- `donnees/` : base de données au format CSV
- `src/` : programmes Python
- `resultats/tableaux/` : tableaux statistiques
- `resultats/graphiques/` : représentations graphiques
- `rapport/` : documents liés au rapport final

## Exécution

pip install -r requirements.txt
python src/analyse_donnees.py
